# The Court (working name)

A cartoon street-basketball court in the browser where brands buy their way in:

| Spot | How it sells | Placeholder price |
|---|---|---|
| Seat | One-time, kept for good. A fan in the brand's colors holds up its card; blocks of seats spell a logo (card stunt). | $5 |
| Banner | Vinyl banners on the sideline barriers and end fences. Anyone can take one for 1.25× its last price. | from $25 |
| Mural | Spray-painted murals on the handball wall and the corner-store wall. Takeover at 1.25×. | from $50 |
| Big screen | The screen on the building over the court, rented by the day. | $29/day |
| Court name | One spot; names the court everywhere (center court, sideline paint, the sign on the building, the page title). Takeover at 1.25×. | from $100 |

Prices live in `src/config.ts`.

## Run it

```bash
npm install
npm run dev        # http://localhost:5190
npm run build      # type-check + production build into dist/
```

- `?demo=1` shows made-up brands (for previews and teaser videos); `?demo=0` shows the empty launch-day court. The Demo button toggles it too.
- `?quality=low|high` forces the graphics level (phones default to low: no ambient occlusion, smaller shadows).
- Drag to orbit, scroll to zoom, click a seat, banner, mural, the big screen, the sign, or center court.
- `T` trailer mode (hides the UI and flies the camera, for screen-recording teasers), `W` starts a crowd wave.

## The 3D models are built in Blender

Everything 3D is generated by Python scripts driving Blender (5.2), then exported as glTF into `public/models/`:

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python blender/build_characters.py -- public/models
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python blender/build_park.py -- public/models/park.glb
```

- `build_characters.py` → `baller.glb` (rigged big-head player with Idle, Run, RunDribble, IdleDribble, Defend, Shoot, Pass, Celebrate) and `fans.glb` (crowd poses). Body regions are stored as codes in the vertex colors so the app can recolor every player and fan without extra draw calls. Add `--preview <dir>` to render still previews.
- `build_park.py` → `park.glb` (court, bleachers, fences, hoops, buildings, lights, trees). Brand spots are named meshes (`CourtSurface`, `BigScreen`, `NamingSign`, `Mural_0..4`, `Banner_0..23`) that the app paints at runtime.
- Positions shared by both sides live in `src/world/park-layout.json`.

## Code layout

- `src/world/park.ts` – swaps in textured materials by name, wires up the brand surfaces, and sets up the sky, sun and lights.
- `src/world/signs.ts` – canvas painters for the court, banners, murals, the big screen and the name sign.
- `src/world/crowd.ts` – instanced fans, card stunts, the wave.
- `src/world/players.ts` – the scripted streetball game driving the animated players.
- `src/render/postfx.ts` – ambient occlusion, bloom, tone mapping.
- `src/data/` – the court's contents; `api.ts` is the single place the state comes from (local demo or empty data for now).
- `src/ui/` – the HTML overlay.
